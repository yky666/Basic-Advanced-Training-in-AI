# Basic & Advanced Training in AI

本仓库用于整理“人工智能基础与进阶实训”课程的大二上、大二下项目代码与运行资料。

## 目录结构

- `大二上/`：大二上期末大作业，主要包含移动机器人导航、建图、路径规划、调度与相关 ROS 工程代码。
- `大二下/`：大二下课程项目，当前保留期末大作业的核心代码目录 `dzy` 与 `limo_ros`。

## 说明

- 仓库不上传项目报告、演示视频、压缩包等大体积提交材料。
- 若需要运行具体项目，请先阅读对应学期目录下的 `README.md`。
- ROS 相关代码建议在课程实验环境或同版本依赖环境中编译运行。
