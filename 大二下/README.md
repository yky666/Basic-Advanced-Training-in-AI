# 大二下课程项目

本目录用于整理大二下“人工智能基础与进阶实训”的课程项目内容。

## 目录结构

- `期末大作业/dzy/`：期末竞赛主要业务代码，包含视觉识别、决策逻辑、语音/视觉接口等实现。
- `期末大作业/limo_ros/`：LIMO 小车 ROS 运行与平台相关代码。

## 上传范围

按照当前整理要求，`期末大作业` 目录只上传 `dzy` 与 `limo_ros` 两个核心代码目录；项目报告、比赛视频、截图文档、压缩包和提交要求文件不上传。

## 运行提示

运行前请确认 ROS、Python 依赖、模型文件路径、串口/摄像头设备名等与实际实验环境一致。若在新机器上部署，建议先分别检查 `dzy` 与 `limo_ros` 内部脚本和启动文件的路径配置。
