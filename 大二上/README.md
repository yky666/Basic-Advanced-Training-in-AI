# 大二上期末大作业

本目录为大二上“人工智能基础与进阶实训”期末大作业内容，原始项目从仓库根目录整理迁移至此。

## 主要内容

- `src/`：ROS 工作空间源码，包含机器人描述、导航、SLAM、遥控、底盘驱动、传感器驱动等模块。
- `map/`：项目使用的地图相关文件。
- `图片/`：项目展示或调试过程中使用的图片资料。
- `启动脚本.txt`：常用启动流程记录。
- `README.txt`：原项目说明文件。

## 运行提示

建议在课程原 ROS 环境中使用 `catkin_make` 或对应构建方式编译 `src/` 工作空间。部分第三方依赖、设备驱动和传感器配置与实验平台绑定，迁移环境时需要同步安装 ROS 包和硬件驱动。
